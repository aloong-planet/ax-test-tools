# AX 场景检查与执行入口

## 概述
供开发者把各项目的原生应用交互场景交给同一个本机测试客户端。每次运行提供独立结果，区分校验通过、运行失败与权限阻断。

## 能力
- 执行前可单独检查场景是否合法，非法动作会被拒绝。
- 可检查辅助功能授权；缺授权时明确阻断，不自动申请权限。
- 可提交隔离应用的交互场景，读取分阶段结果；启动成功不会被当作测试通过。

## 边界与不做
- 后台可操作性取决于目标应用的辅助功能支持；不保证所有Swift应用兼容。
- 不替代真实鼠标、键盘焦点与视觉验收。权限需要用户手工授予。
- 不会自动强制激活应用或改用桌面鼠标键盘事件；检测前台变化时失败。此检查不是操作系统级焦点隔离。
- 只使用可信场景与隔离数据；同一目标不可并发测试。
